## Tipos de datos

| SadScript   | Significado         | Ejemplo                       |
| ----------- | ------------------- | ----------------------------- |
| `dolor`     | Entero (`int`)      | `dolor edad = 20;`            |
| `vacio`     | Flotante (`float`)  | `vacio promedio = 3.14;`      |
| `esperanza` | Booleano (`bool`)   | `esperanza ok = vivo;`        |
| `recuerdo`  | Cadena (`string`)   | `recuerdo msg = "hola";`      |
| `cicatriz`  | Vector / arreglo 1D | `cicatriz nums = [1,2,3];`    |
| `trauma`    | Matriz / arreglo 2D | `trauma mat = [[1,2],[3,4]];` |

## Literales y valores

| SadScript | Token interno      | Tipo                |
| --------- | ------------------ | ------------------- |
| `vivo`    | `TRUE`             | Booleano verdadero  |
| `muerto`  | `FALSE`            | Booleano falso      |
| `nulo`    | `NULO`             | Valor nulo          |
| `"texto"` | `LITERAL_CADENA`   | Cadena de texto     |
| `'a'`     | `LITERAL_CARACTER` | Carácter individual |
| `42`      | `LITERAL_ENTERO`   | Número entero       |
| `3.14`    | `LITERAL_DECIMAL`  | Número flotante     |
| `1.5e10`  | `LITERAL_DECIMAL`  | Notación científica |

<SadCodeBlock
  code={`esperanza x = vivo      // true
esperanza x = muerto    // false
nulo                    // null
recuerdo x = "texto"    // cadena
dolor x = 'a'           // caracter
dolor x = 42            // entero
vacio x = 3.14          // flotante
vacio x = 1.5e10        // notación científica`}
/>

## Break y Continue

| SadScript          | Token interno | Descripción                    |
| ------------------ | ------------- | ------------------------------ |
| `cortarme`         | `BREAK`       | Sale del bucle actual          |
| `seguir_fingiendo` | `CONTINUE`    | Salta a la siguiente iteración |

<SadCodeBlock
  code={`cortarme;              // break
seguir_fingiendo;      // continue`}
/>
